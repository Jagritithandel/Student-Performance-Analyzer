# Student-Performance-Analyzer

## Description
A beginner-level Python project that calculates and displays a student's total marks, average marks, highest marks, lowest marks, and overall result using Python lists and functions.

## Concepts Used
- Lists
- Functions
- Loops
- Conditional Statements
- User Input
- Built-in Functions

## Features
- Accepts marks for multiple subjects
- Calculates total and average
- Finds highest and lowest marks
- Displays Pass/Fail result

## How to Run
Run the `student_performance_analyzer.py` file using Python.

## Example
Enter student name: Jagriti
Total no. of subjects: 3
Enter marks for subject 1: 80
Enter marks for subject 2: 75
Enter marks for subject 3: 90
